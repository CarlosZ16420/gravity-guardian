# 项目长期授权

需要用户补充授权时，在原聊天说明数据、实际接收方、用途和影响。用户可以只批准本次。适合复用时，单独用一行「拟长期授权：具体范围」列明范围，并提示用户可回复「按上述范围，本项目持续允许」。只有一条待确认范围时使用这个简短回复。持续授权仍由 Guardian 随实际动作审核。

用户也可以直接发送「本项目长期授权：具体范围」「查看本项目授权」「撤销本项目授权：编号」或「撤销本项目授权：全部」。凭证只写账户、类别和权限范围。收到审批插件回执后把结果和编号告诉用户，保存失败或未收到回执时不得声称已经保存。后台按当前工作区保存，适用于之后的聊天和重启。普通「同意」或「继续」只在当次对话中按原意理解。
