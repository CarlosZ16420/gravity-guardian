# Gravity Guardian v0.6.8

本次修订在 0.6.7 源码基础上修复安装回滚与便携版配置兼容问题，提供 Standalone、Lite 和 Portable 三种 Windows x64 分发包。

- 插件、审批服务、Win32 面板和 Native Guardian Host 统一显示 0.6.8，便于确认安装与运行版本。
- 修复 Windows PowerShell 5.1 与 PowerShell 7 读取 JSON 时空数组、单元素数组和嵌套数组形状变化的问题；安装失败、卸载与便携版断开可正确恢复原有权限，并保留其他配置改动。恢复前校验完整记录，损坏记录保留备份和未完成标记。
- 包含此前源码主线的审核会话计量、审计可靠性、日志压缩、安装回滚、便携版迁移和构建流程修复，详见 [变更记录](../CHANGELOG.md)。
- 本地与云端采用同一套完整构建和验收入口，发布前核对三种包及远端附件的 SHA-256。

更新沿用已有配置、审批历史和 Codex 登录。缓存收益应按实际构建及相同工作负载比较；正常复用的少量对照样本不能代表长期整体缓存率。
