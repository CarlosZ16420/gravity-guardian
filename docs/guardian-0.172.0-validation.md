- `codex-auto-review` 的上游内置目录窗口为 272,000 token。按默认 95% 系数和 256 token 余量计算，内置目录情形的审核输入上限为 258,144 token，再由预检与最终组包扣除当前上下文、请求结构和宿主事实。实际使用上游解析出的模型窗口。弹性分区对 128,000 token 的名义保留量作校验，父会话继续按 96,000 已用输入 token 或 64 次审核轮换。
- 外部入口沿用同步审核。预检和组包共用上游弹性分配，完整动作、验证过的用户指令和问答受保护。单个写入或编辑本身超限时返回拆分重试，授权留存不足时阻止自动批准。

## 候选版说明

安装、修复与更新使用随包的 `ag-guardian-host.exe`。面板的「Guardian 登录」与 `Doctor.ps1` 使用同一凭据探测。`credentials_found` 表示 Guardian 可以读取本机凭据。历史日志、已有授权和自定义凭据目录由升级流程保留。

运行 `Build.ps1` 后，用 `node scripts/Test-NativePrompt.mjs .local/prompt-test` 可生成两份模拟请求和摘要。此测试只连接本机模拟端点，使用合成脚本和测试凭据。

用 `scripts/Test-NoCli.ps1 -OutputDirectory .local/no-cli-test` 可复跑 Windows 进程跟踪，结果写入指定目录的 `summary.json`。[候选版发布说明](release-native-guardian.md)

合并接管热开关后，隔离回归验证了修复和自更新都会保留暂停状态，暂停时也能完整卸载。该轮记录到 90 次进程启动，`codex.exe` 仍为 0 次。
