# Gravity Steward v0.6.1

Gravity Steward 的首个公开版本，为 Windows x64 上的 Antigravity 提供 Codex 工具审批。

- 使用 Codex Guardian 审核工具请求，并保留 Antigravity 的显式权限规则。
- 托盘面板支持安装、修复、查看用量和检查更新。详细日志默认关闭。
- 减少重复提交的审核上下文，统计面板区分零次推理和用量缺失。

下载 `gravity-steward-0.6.1-windows-x64.zip`，对照 `checksums.sha256` 校验后完整解压。退出 Antigravity，再运行 `GravitySteward.exe` 安装。需要已登录且能访问审核模型的 Codex 账号。
