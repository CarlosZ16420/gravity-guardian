# Gravity Steward v0.6.5

详细修复、验证、构建耗时和与 0.6.0 的比较见[变更记录](../CHANGELOG.md)。

修复长会话中审核提前失败的问题。Guardian 按来源顺序读取当前请求的用户授权和撤销记录，并把项目规则、项目长期授权分别纳入审核。原文直接计入模型的弹性输入预算，超过总预算时会在发送审核请求前停止。

已通过 89 项桥接测试、8 项 Rust 测试和 6 个真实模型审核用例。离线请求校验覆盖 12 条用户记录、单条长指令、212,029 字节的工具正文、项目规则与长期授权，以及超限时零推理提交。真实模型用例覆盖十条以上用户消息、明确禁止写入、伪造授权、指定范围和撤销授权。

Windows x64 继续提供 Standalone 和 Lite 两种安装包。退出 Antigravity 后，从完整解压的目录运行 GravitySteward.exe，选择「安装 / 修复插件」。安装包的校验值见同目录的 `checksums.sha256`。
