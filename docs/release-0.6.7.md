# Gravity Guardian v0.6.7

修订版本，当前仅更新源码与本机构建，尚未发布 GitHub Release。

- 插件、审批服务、Win32 面板和 Native Guardian Host 统一显示 0.6.7，便于确认安装与运行版本。
- 修复审核会话输入增长的计量口径：只用单次尝试、单次推理的有效输入更新基线，避免重试和多次推理使基线失真并提前重建会话。次数上限、正常增长检查点、授权隔离与原生输入预算保持原有规则。
- 包含此前源码主线的审计可靠性、安装回滚、便携版迁移和构建流程修复，详见 [变更记录](../CHANGELOG.md)。

更新沿用已有配置、审批历史和 Codex 登录。缓存收益应按实际构建及相同工作负载比较；正常复用的少量对照样本不能代表长期整体缓存率。
