# Gravity Steward v0.6.2

面板版支持后台版 0.5.2 的项目长期授权。仍在 Antigravity 聊天中保存、查看和撤销授权。同一数据目录里的已有授权可直接沿用。[聊天命令](../plugin/README.md)

面板新增「完整卸载」。完全退出 Antigravity 后，在面板中确认卸载。Gravity Steward 会退出面板、停止审批服务、移除已安装的插件和开机启动项，并永久删除本地审批日志、统计、设置、项目长期授权、缓存和备份。

卸载会恢复 Gravity Steward 修改过且之后未经编辑的 Antigravity 权限设置。手动下载的 ZIP 和解压目录可自行删除。

下载并完整解压 `gravity-steward-0.6.2-windows-x64.zip`。可用同目录的 `checksums.sha256` 校验下载。
